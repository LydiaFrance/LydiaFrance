How to Use

  • Select modes: Click the mode buttons to switch between different morphing patterns
  • Play/Pause: Use the play/pause controls to animate the wing changes
  • Explore: Each mode shows how wings deform in that particular pattern

Understanding the Visualization

  • 3D Model: Shows the hawk's wing and tail shape changes
  • Time Series: The small plot shows how the mode value changes over time
  • Red Dot: Indicates the current frame in the animation
